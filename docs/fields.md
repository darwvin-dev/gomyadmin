# Fields

Supported field families include strings, text, email, password, numbers, decimal, money, booleans, enums, status badges, dates, UUIDs, JSON/JSONB, markdown, rich text, images, files, relations, and computed fields.

Field capabilities include required, unique, nullable, searchable, sortable, filterable, readonly, hidden, default values, validation, help text, placeholders, badge colors, custom renderers, formatters, parsers, and relation display fields.
